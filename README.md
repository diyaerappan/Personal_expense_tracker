
# Personal Expense Tracker

## Overview

Personal Expense Tracker is a beginner-friendly Python project that allows users to record and manage daily expenses. The program stores expense details, calculates total spending, and identifies the highest expense.

## Features

- Add new expenses
- View all expenses
- Calculate total spending
- Find highest expense
- Menu-driven interface

## Technologies Used

- Python

## Concepts Covered

- Variables
- Data Types
- Lists
- Tuples
- Loops
- Conditional Statements
- User Input

## Sample Expense Record

('Food', 250)
('Travel', 100)
('Books', 500)
